# Shivam Gaikwad – Business Analyst Portfolio (React + Vite)

## Run locally
```
npm install
npm run dev
```
Build for production: `npm run build` (output in `dist/`). Deploy `dist/` to Vercel, Netlify or GitHub Pages.

## Customise
- All text lives in `src/data.js` (profile, skills, experience, projects, education).
- Your photo is at `public/photo.webp` (replace it to change the photo; portrait, about 4:5). Initials show if the file is missing.
- Colours and light/dark theme tokens are at the top of `src/index.css`.
- Replace the illustrative case studies in `data.js` with your real work where you can.
